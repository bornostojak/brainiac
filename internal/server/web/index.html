Agents update this board through REST or MCP. Progress estimates, context capacity, token budgets and account allowance are separate readings.

Download install.sh, inspect it, then run it. The installer asks which installed harnesses to use and whether to configure MCP.

curl -fsS http://127.0.0.1:3011/install.sh -o /tmp/brainiac-install.sh
sh /tmp/brainiac-install.sh --url http://127.0.0.1:3011
