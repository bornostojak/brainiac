# Vendor icon sources

These small marks identify the model vendor reported by an agent. They do not
imply endorsement. Browsers load the bundled assets from Brainiac, without
requests to vendor sites. Vendor trademarks belong to their respective owners.

- OpenAI: [Lobe Icons SVG](https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/openai.svg), retained under the accompanying MIT license. [OpenAI brand guidance](https://openai.com/brand/).
- Anthropic: [official site favicon](https://cdn.prod.website-files.com/67ce28cfec624e2b733f8a52/681d52619fec35886a7f1a70_favicon.png), linked from [Anthropic](https://www.anthropic.com/).
- Z.ai: [official site logo](https://z-cdn.chatglm.cn/z-ai/static/logo.svg), linked from [Z.ai](https://chat.z.ai/).
- Google: [official Google icon](https://www.google.com/images/branding/googleg/1x/googleg_standard_color_128dp.png).

Unknown and other vendors use a local initial badge. SVG files were inspected
for scripts, external references and embedded content before bundling.
